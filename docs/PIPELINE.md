# 实验细节 Experiment Details

本仓库配套的实现细节说明。数据、训练与部署脚本整理后将陆续开源（见 [Roadmap](../README.md#roadmap)）。

## 1. 硬件搭建与标定

- **臂与夹爪**：AgileX PiPER（6 自由度），末端二指平行夹爪，夹爪开合由末端 IO 控制。
- **感知**：腕装 Intel RealSense D435，采集 RGB-D（848×480 @ 30 Hz）。
- **手眼标定**：eye-in-hand 配置。末端按预设姿态序列采集 AprilTag (36h11) 图像，用 OpenCV `calibrateHandEye`（Tsai-Lenz）求解相机-末端外参；标定残差以重投影误差与末端到标志物的实测距离双重验证。

## 2. 数据采集与清洗

| 项目 | 数值 |
|---|---|
| 遥操作轨迹 | 96 条 |
| 清洗后保留 | 78 条（81%） |
| 总时长 | ≈ 2.1 小时 |
| 总帧数 | ≈ 22,000 |
| 物体 | 木质方块 12 个 / 6 类（2 色 × 3 尺寸），2 类 held-out |

清洗规则：剔除采集过程中的失败尝试、夹爪未闭合帧段、深度丢帧段；对图像-关节-夹爪状态做时间戳软对齐（最近邻 + 100 ms 容差）；语言指令按任务模板批量标注。

## 3. 训练配置

- 框架：**openpi**；初始化权重：**π0.5** 预训练 checkpoint
- 策略：action expert **全参数微调**；VLM 主干 **LoRA (r=16, alpha=32)**
- 精度：bf16；优化器：AdamW，学习率 2.5e-5（cosine 衰减 + 500 step warmup）
- 硬件：2 × RTX 4090，global batch 16，15k steps，约 14 小时
- 数据增强：随机裁剪 / 颜色抖动（模拟光照变化，缓解真机光照泛化问题）

## 4. 端侧部署

- 导出：PyTorch → ONNX → **TensorRT FP16**（Jetson Orin NX 16GB）
- 推理：单步 **68 ms**；模型输出 10 步 action chunk，滚动执行（每 4 步重推理一次），控制回路 **~15 Hz**
- 观测：RealSense RGB-D 预处理（resize / 归一化 / 深度对齐）计入端到端延迟

## 5. 评测协议

- 每项任务 **25 次 rollout**，物体初始位姿在工作空间内随机扰动
- 成功判定：抓起并稳定搬运至目标区域，放置后物体无倾倒
- 失败案例逐条记录并归因（见 README「失败模式分析」）
